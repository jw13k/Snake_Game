# Neon Snake Game

## 1. 개요 및 목적
**네온 스네이크(Neon Snake)**는 고전 스네이크 게임을 현대적인 사이버펑크 스타일로 재해석한 웹 기반 아케이드 게임입니다.
네온 비주얼과 효과음, 그리고 단계별 스테이지 시스템을 통해 단순한 점수 획득을 넘어선 성취감을 제공하는 것을 목적으로 합니다.
최신 웹 브라우저 환경에서 별도의 설치 없이 즉시 즐길 수 있도록 최적화되어 있습니다.

## 2. 기술 스택
이 프로젝트는 순수 웹 표준 기술만을 사용하여 개발되었습니다.
- **HTML5**: 시맨틱 마크업 및 게임 구조 정의
- **CSS3**: 네온 글로우(Glow) 효과, 애니메이션(`@keyframes`), 반응형 레이아웃 (Flexbox)
- **Vanilla JavaScript**: 게임 루프, 충돌 처리, 상태 관리, 오디오 시스템 구현 (No external libraries)
- **Canvas API**: 고성능 2D 그래픽 렌더링
- **Web Audio API**: 실시간 효과음 합성 및 재생 (신디사이저 방식)

## 3. 설치 방법
이 게임은 정적 웹 페이지로 구성되어 있어 복잡한 설치 과정이 필요 없습니다.

1. **소스 코드 확보**: 제공된 프로젝트 폴더(`snakegame`)를 준비합니다.
2. **파일 확인**: 폴더 내에 다음 핵심 파일들이 있는지 확인합니다.
   - `index.html`, `game.html`
   - `style.css`
   - `game.js`, `menu.js`, `common.js`
   - `image/` 폴더 (스프라이트 이미지 포함)

## 4. 실행 방법
1. **로컬 실행**:
   - `index.html` 파일을 더블 클릭하여 웹 브라우저(Chrome, Edge, Firefox 등)에서 실행합니다.
   - VS Code를 사용하는 경우 'Live Server' 확장을 이용하면 더욱 원활하게 실행할 수 있습니다.

2. **게임 조작**:
   - **이동**: `W`, `A`, `S`, `D` 또는 방향키 (`↑`, `↓`, `←`, `→`)
   - **시작/선택**: `Space` 키 또는 마우스 클릭
   - **일시정지/메뉴**: `ESC` 키

## 5. 제공 기능 (`Features`)
### 🎮 게임플레이
- **다양한 스테이지 모드**:
  - **Score Mode**: 목표 점수를 달성하면 클리어 (Soldier 스테이지)
  - **Wave Mode**: 쏟아지는 적 웨이브와 보스 패턴을 버티면 클리어 (Boss 스테이지)
- **성장 시스템**: 플레이어 데미지 상태에 따른 이미지 변화 및 회복 시스템

### 🎨 비주얼 & 오디오
- **동적 연출**:
  - 적 페이즈 변화 및 플레이어 피격 시 **화면 흔들림(Shake)** 및 **붉은 섬광(Red Flash)** 효과
  - 점수 획득 및 레벨업 시 화려한 네온 이펙트
- **반응형 사운드**: 상황(먹기, 피격, 레벨업 등)에 따라 실시간으로 합성되는 효과음

### ⚙️ 시스템
- **데이터 저장**: `localStorage`를 이용한 **최고 점수(High Score)** 및 **스테이지 해금(Unlock)** 상태 자동 저장
- **사용자 설정**: 배경음 볼륨, 화면 밝기, 언어 설정 지원
